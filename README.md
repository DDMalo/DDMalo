## 🚀 What I'm building

**🍯 [IA-Honeypot](https://github.com/DDMalo/IA-Honeypot)** · *solo project, in progress*
SSH/Telnet honeypot that captures real attacks with Cowrie, enriches them with GeoIP and IP-reputation data, and maps each session to **MITRE ATT&CK**. It compares rule-based, cloud-LLM and local-model classifiers against a hand-labelled dataset.

**🎙️ [Chilluevar](https://github.com/DDMalo/Chilluevar)** · *team of two, in progress*
Fully local, privacy-first voice assistant: wake word, speech-to-text, an LLM with tools and text-to-speech, with no audio ever leaving the machine. I own the audio pipeline, integrations, security and deployment.
